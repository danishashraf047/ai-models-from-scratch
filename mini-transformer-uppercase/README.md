# Mini Transformer: Text-to-Text Uppercase Learning

A complete **randomly initialized** encoder-decoder Transformer implemented with PyTorch. Learns from generated lowercase → uppercase text pairs. No pretrained model or hosted AI API is used.

## Requirements

Python 3.10+ recommended. PyTorch supports CPU, NVIDIA CUDA, and Apple Silicon MPS depending on installation.

```bash
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Generate dataset

```bash
python dataset.py
```

Generates `data/train.jsonl`, `data/val.jsonl`, and `data/test.jsonl`. Different sentences are assigned to each split. The same vocabulary is used in all splits. Training examples are generated by applying Python `.upper()` **only to the labels**, never to the model output.

## Smoke test

```bash
python test_project.py
```

This verifies shapes and gradients, **not** that the untrained model is accurate.

## Train

```bash
python train.py --epochs 30 --batch-size 64
```

For a quicker initial experiment:

```bash
python dataset.py --train-size 2000 --val-size 200 --test-size 200
python train.py --epochs 5 --batch-size 32 --d-model 64 --layers 1
```

Training can be slow on CPU. Accuracy is per target token under teacher forcing, not exact full-sentence generation accuracy. More epochs or hyperparameter tuning may be needed to generalize.

## Inference

```bash
python inference.py --text 'hello danish how are you'
```

Output is generated character-by-character by the trained network. The printed `Target` is a comparison string, not used by the model.

## Core components

- `tokenizer.py`: fixed character vocabulary and special tokens `<pad>`, `<bos>`, `<eos>`, `<unk>`.
- `dataset.py`: synthetic unique sentences and uppercase labels.
- `model.py`: learned character embeddings, sinusoidal positional encoding, encoder-decoder self-attention and cross-attention, and vocabulary projection.
- `train.py`: teacher forcing, causal target mask, padding masks, cross-entropy, AdamW, validation and best-checkpoint saving.
- `inference.py`: greedy autoregressive decoding from the start-of-sequence token.
- `test_project.py`: basic smoke tests.

## Limitations

- Inputs use a limited character vocabulary. Unsupported characters become `<unk>` and cannot be reconstructed faithfully.
- Maximum sequence length is 128 tokens, and the inference output is capped at 80 generated tokens.
- A Transformer may struggle to learn perfect character copying from modest data; this is an educational model, not a replacement for deterministic `.upper()`.
- Training examples are constructed from a small word list, so performance on unusual strings may be poor.
- This is trained from random weights, but it uses PyTorch's existing `nn.Transformer` implementation rather than hand-coding attention kernels.
